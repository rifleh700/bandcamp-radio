# bandcamp-radio

Tiny console bandcamp radio. It plays random tracks by given tags, u can browse it on "Discover" Bandcamp page (https://bandcamp.com/discover).

For run unpack ZIP after building and run `run.sh`.

This project based on [OpenAPI declaration of public Bandcamp endpoints](https://github.com/rifleh700/bandcamp-public-openapi)

Uses:
 - JAX-RS/Resteasy client
 - JSON-B(P)/Yasson
 - OpenAPI generator
 - Zoom JLayer
